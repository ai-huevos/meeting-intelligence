# Meeting OS Production Deployment Checklist

## 1. Cloud & Python Environment
- [ ] **Provision Server**: Set up a VPS (AWS EC2, DigitalOcean, or Railway/Render) to run the Python agents.
- [ ] **Python Version**: Ensure Python 3.10+ is installed.
- [ ] **Environment Variables**:
    - Copy content of `.env` to the production environment secrets.
    - Ensure `GOOGLE_API_KEY`, `PERPLEXITY_API_KEY`, `SLACK_BOT_TOKEN`, `NOTION_PARENT_PAGE_ID` are set.
    - [Optional] Add `GOOGLE_APPLICATION_CREDENTIALS` (JSON content) for Calendar.
- [ ] **Install Dependencies**: Run `pip install -r requirements.txt`.

## 2. Notion Setup
- [ ] **Run Schema Deployer**:
    - Execute `python meeting_os/lib/schema/schema_deployer.py` against the **Production** Workspace.
    - Note the returned Database IDs (Meeting, Company, Opportunity).
- [ ] **Update IDs**: Update the `NOTION_X_DB_ID` variables in your environment or `agent-templates/sales_agent_template.json` to match the *production* database IDs.

## 3. n8n Workflow
- [ ] **Import Workflows**:
    - Import `sales_workflow.json` into your production n8n instance.
    - Import any future workflows generated by `generator.py`.
- [ ] **Configure Webhooks**:
    - Update the **Webhook URL** in the Meeting Recorder (Fireflies/Grain) to point to your production n8n webhook.
- [ ] **Verify Authentication**:
    - Ensure n8n has the "Google Gemini" or "HTTP Request" credentials configured if not using the embedded API key in the JSON.

## 4. Final verification
- [ ] **Test Call**: Record a 5-min test meeting.
- [ ] **Verify Logs**: Check `meeting_os/logs/events.jsonl` (or your cloud logger) for "workflow.started".
- [ ] **Verify Notion**: Confirm a new page appears in the "Meetings" DB and "Opportunities" DB.
