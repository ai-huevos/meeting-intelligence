# Meeting Templates

## 1:1 Template

**Goal:** [Objetivo de la reunión]

**Energy Audit:**
- Energía del fundador: [1-10]
- ¿Es la mejor hora para esta conversación?
- ¿Hay bloqueos previos a abordar?

**Status Updates (2 min cada uno):**
1. [Name] → [Status de Top Goal + Blockers]
2. [Name] → [Status de Top Goal + Blockers]

**Decisions (RAPID):**
- **R**ecommender: [Quién recomienda]
- **A**gree: [Quién aprueba]
- **P**erform: [Quién ejecuta]
- **I**nput: [Quién consulta]
- **D**ecide: [Quién decide]

**Next Actions:**
- [ ] [Who] → [What] → [By When]

## Feedback Script (Ask → Fact → Emotion → Request)

1. **Ask:** "Puedo darte feedback sobre [situation]?"
2. **Fact:** "Observé que [specific behavior]..."
3. **Emotion:** "Me sentí [emotion] porque [impact]..."
4. **Request:** "En el futuro, prefiero [specific request]..."

**Regla:** Pedir permiso primero, separar hechos de emociones.
